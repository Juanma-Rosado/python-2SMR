# Python · 2.º SMR

Los ejercicios, prácticas y exámenes de Python que hice en segundo de SMR (curso 2025-2026), por temas.

Necesitan Python 3.10 o más nuevo, porque algunos usan `match`. Para probar uno:

```bash
python 02-Bucles/ejercicios-for/1.py
```

Los que tienen varios ficheros, como el examen de POO, hay que lanzarlos desde su carpeta. Muchos limpian la pantalla con `cls`, así que en Linux no la limpian.
